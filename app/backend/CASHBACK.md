# Кэшбэк за календарный месяц

Спецификация программы лояльности «Кошелька». Документ первичен по отношению
к коду `wallet/cashback.py` — так же, как `spec/openapi.yaml` первичен по
отношению к обработчикам. Если поведение кода расходится с этим документом,
правится код.

Все суммы — рубли, `Decimal` с двумя знаками. Валюта одна, `RUB`.

---

## 1. Из чего складывается оборот месяца

Оборот месяца — это то, что человек за месяц **потратил**.

| Тип операции | Идёт в оборот | Почему |
|---|---|---|
| `WITHDRAW` | да | это и есть трата |
| `TOPUP` | нет | пополнение — перекладывание своих денег, не покупка |
| `FEE` | нет | комиссия удерживается нами, начислять кэшбэк на свою же комиссию нельзя |

Месяц операции определяется по её метке времени `created_at`, которая
приходит в UTC (`2026-09-08T12:04:11Z`). Операция относится к месяцу
`2026-09`, если её метка начинается с `2026-09`.

Оборот считается по операциям одного кошелька. Операции других месяцев
в сумму не входят.

### Контрольные значения

История одного кошелька:

| operation_id | type | amount | created_at |
|---|---|---|---|
| 1 | `WITHDRAW` | 1 000,00 | `2026-09-03T10:00:00Z` |
| 2 | `FEE` | 15,00 | `2026-09-03T10:00:00Z` |
| 3 | `TOPUP` | 5 000,00 | `2026-09-05T09:00:00Z` |
| 4 | `WITHDRAW` | 2 500,50 | `2026-09-28T21:00:00Z` |
| 5 | `WITHDRAW` | 900,00 | `2026-08-30T12:00:00Z` |

| Вход | Ожидается | Почему |
|---|---|---|
| месяц `2026-09` | `3500.50` | операции 1 и 4; комиссия и пополнение в оборот не идут |
| месяц `2026-08` | `900.00` | одна операция 5 |
| месяц `2026-07` | `0.00` | операций месяца нет |

## 2. Ставка по обороту

Ставка определяется по **обороту месяца целиком** и одинакова для всей
суммы оборота: это не прогрессивная шкала, ступень только выбирает процент.

| Оборот за месяц | Ставка |
|---|---|
| до 3 000,00 ₽ включительно | 0 % |
| свыше 3 000,00 ₽ и до 30 000,00 ₽ включительно | 1 % |
| свыше 30 000,00 ₽ | 2 % |

Тариф кошелька: кэшбэк начисляется только на `BASIC`. На `FREE` операции
бесплатные, кэшбэка нет ни при каком обороте — ставка 0 %.

Границы принадлежат нижней ступени: оборот **ровно** 3 000,00 ₽ даёт 0 %,
оборот **ровно** 30 000,00 ₽ даёт 1 %. Повышенная ставка начинается
с 30 000,01 ₽.

### Контрольные значения

| Оборот | Тариф | Ожидается | Почему |
|---|---|---|---|
| 0,00 | `BASIC` | 0 % | трат нет |
| 2 999,99 | `BASIC` | 0 % | ниже порога |
| 3 000,00 | `BASIC` | 0 % | порог включается в нижнюю ступень |
| 3 000,01 | `BASIC` | 1 % | первая копейка сверх порога |
| 25 000,00 | `BASIC` | 1 % | середина базовой ступени |
| 30 000,00 | `BASIC` | 1 % | верхняя граница базовой ступени включается в неё |
| 30 000,01 | `BASIC` | 2 % | первая копейка сверх базовой ступени |
| 40 000,00 | `BASIC` | 2 % | повышенная ступень |
| 40 000,00 | `FREE` | 0 % | на этом тарифе кэшбэка нет |

## 3. Сколько начисляется

1. Берём оборот месяца (раздел 1).
2. Берём ставку по обороту и тарифу (раздел 2).
3. Начисление = **оборот × ставка**. Ставка применяется ко всей сумме
   оборота, а не к превышению над границей ступени.
4. Результат округляется до копеек по правилу «половина вверх» — так же,
   как считаются все остальные деньги в продукте (`wallet/money.py`).
5. Потолок месяца — **2 500,00 ₽**. Если после округления получилось
   больше, начисляем ровно 2 500,00 ₽. Потолок применяется к начислению,
   а не к обороту.

### Контрольные значения

Тариф `BASIC`, если не указано иное.

| Оборот | Ставка | Ожидается | Почему |
|---|---|---|---|
| 0,00 | 0 % | `0.00` | трат нет |
| 2 999,99 | 0 % | `0.00` | ниже порога |
| 3 000,00 | 0 % | `0.00` | порог в нижней ступени |
| 3 000,01 | 1 % | `30.00` | 30,0001 округляется до 30,00 |
| 12 345,67 | 1 % | `123.46` | 123,4567 округляется до 123,46 |
| 25 000,00 | 1 % | `250.00` | ровное значение |
| 29 999,99 | 1 % | `300.00` | 299,9999 округляется до 300,00 |
| 30 000,00 | 1 % | `300.00` | граница базовой ступени, ставка ещё 1 % |
| 30 000,01 | 2 % | `600.00` | 600,0002 округляется до 600,00 |
| 40 000,00 | 2 % | `800.00` | 2 % со всей суммы оборота |
| 125 000,00 | 2 % | `2500.00` | ровно потолок |
| 200 000,00 | 2 % | `2500.00` | 4 000,00 срезаны потолком |
| 40 000,00, тариф `FREE` | 0 % | `0.00` | на `FREE` кэшбэка нет |

Правила раздела определяют результат для любой суммы; таблица — контрольные
точки, по которым удобно писать тесты.

## 4. Что где лежит

| Что | Где |
|---|---|
| Оборот месяца | `monthly_turnover(operations, month)` |
| Месяц операции | `operation_month(created_at)` |
| Ставка | `cashback_rate(turnover, tariff)` |
| Начисление по обороту | `cashback_for_turnover(turnover, tariff)` |
| Начисление по истории | `monthly_cashback(operations, month, tariff)` |

`operations` — те же словари, что уходят клиенту в истории
(`OperationView.to_item`): поля `type`, `amount`, `created_at`.
`month` — строка вида `2026-09`.

Модуль не ходит в базу и не читает окружение: на вход список операций,
на выход числа. Проверить можно из `app/backend`:

```bash
python3 -c "import sys; sys.path.insert(0,'.'); import wallet.cashback"
```

## 5. Где это видно пользователю

`GET /api/wallet/cashback` — оборот текущего месяца, ставка и начисление
по кошельку вызывающего. Контракт эндпоинта — в `spec/openapi.yaml`,
числа — по этому документу.
